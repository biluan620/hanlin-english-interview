麦克风与语音识别

每个麦克风后面的「试听 3 秒」会真的打开它听一下：峰值到 1.5 以上才算能收到声音。 蓝牙耳机的麦克风经常显示正常但一点声音都收不到，遇到这种就换一个。

云端语音识别

填好之后，学生说话由云端模型转成文字（只发这几秒的录音，不带姓名、不带前面的问答记录）。 没填 Key 时会自动用浏览器自带听写，功能不会少。
· 硅基流动（推荐）：注册后创建 API Key，模型填 FunAudioLLM/SenseVoiceSmall，很便宜，中文口音的英语也认得准。
· 智谱：开放平台的 API Key，模型填 glm-asr。
· 识别出来的原文会显示在屏幕上，老师随时可以改；记录表里也会分开存「学生原话」和「提交的答案」。
