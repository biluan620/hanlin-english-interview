# HanLin 英语采访（离线版）· 使用说明

一个会说话的小记者：他用初二水平的英语按固定顺序问三个问题，**学生对着麦克风说英语、页面自动转成文字**，HanLin 当场接话——没有语法错误就说 `Great!` / `Good job!`；有语法错误就**把学生那句话直接改对**，屏幕上并排显示原句和改后句。整节课下来就像 HanLin 真的在和学生对话。

**不用装任何东西、不用注册、不用填 Key。** HanLin 的声音、三个问题、点评都在文件里；唯一需要联网的是"听学生说话"那一步（浏览器把声音送去识别）。

**上课推荐双击 `启动采访-不询问麦克风.bat`**：它会用 Edge 打开采访页，并且**麦克风不会弹询问**，直接就能收音。

## 上课怎么用（语音版）
### 桌面版：双击就是一个独立窗口，不经过浏览器

**用法**：双击 `HanLin采访-桌面版.exe` → 直接出现一个「HanLin 英语采访」窗口（启动就是最大化）。

| 对比 | 桌面版 | 用 .bat 打开 |
| --- | --- | --- |
| 长什么样 | 自己的窗口，没有地址栏、没有标签页 | Edge 的窗口（有浏览器外壳） |
| 麦克风询问 | **一次都不弹**（程序自动允许） | 一次都不弹（靠启动参数） |
| 听写 | 一样（Edge 的听写服务，需联网） | 一样 |
| 首次运行 | Windows 可能提示"已保护你的电脑"，点**更多信息 → 仍要运行** | 不会有这个提示 |

两个注意点：

1. **`HanLin采访-桌面版.exe` 和那 3 个 `.dll`、以及 `HanLin采访-离线版.html` 必须待在同一个文件夹里**，少一个都打不开（程序会弹中文提示告诉你缺什么）。
2. **桌面版的记录和 AI Key 跟浏览器版是分开存的**（浏览器按"来源"分别保存）。第一次用桌面版，AI Key 要重新填一次；以前的记录还在浏览器版里，导出的 CSV 不受影响。

想恢复出厂：删掉 `C:\Users\你的用户名\AppData\Local\HanLin采访桌面版` 这个文件夹即可（只影响桌面版的记录和设置）。

**`.exe` 打不开怎么办**：改用 `上课-独立窗口.bat`，它用 Edge 的独立窗口模式打开同一个采访页，同样是"没有地址栏、没有标签页"的窗口，麦克风也不会弹询问。


1. **双击 `启动采访-不询问麦克风.bat`**（推荐）。它会用 Edge 打开采访页，麦克风自动允许、不弹询问；打开后按 **F11** 全屏。
   如果直接双击 `HanLin采访-离线版.html` 也可以，但浏览器会问一次麦克风权限，点**允许**即可。
   也可以直接放映课件，在第 1、5、6、7、8 页点蓝色的 **Start the interview**。
2. 鼠标移到**屏幕顶端**（或按 **Esc**）弹出老师控制条 → 填组名 → 点**开始采访**。
3. HanLin 问完第 1 题后，学生点 **🎤 Answer**（或按**空格**）开始说英语；说完停顿一下会自动停止，文字出现在屏幕上的框里，再过一秒自动提交。
4. HanLin 立刻接话：

   - 没有语法错误 → `Great!` / `Good job!`
   - 有语法错误 → `Good try. A small tip:`，同时屏幕上出现两行：

     ```
     You said          We are both like music and I am agree with he.
     Say it like this  We both like music and I agree with him.
     ```

     第一行里错的词标红划掉，第二行里改对的词绿色高亮。

5. 点 **Next question** 进下一题；三题问完是收尾台词；改好组名点 **Next group** 继续下一组。
6. 课后：控制条 → **记录** → **导出 CSV**，Excel 直接打开。

**没听清怎么办**：HanLin 会说 `Sorry, I didn't catch that. Please say it again.` 并等你重说，不会跳题。

**识别错了怎么办**：框里的文字可以直接改，改完按回车提交；已经点评完了就点**改判 / 手动点评**重新给一句。

## 控制条上有什么

| 按钮 | 作用 |
| --- | --- |
| 组名 | 这一组的名字，会写进记录 |
| 开始采访 / 下一组 | 开始一组 / 换下一组 |
| 重听这句 | 学生没听清时重放当前这句 |
| 跳过这题 | 不点评，直接进下一题 |
| 语音输入：开 / 关 | **开**（默认）：HanLin 问完**自动开始收音**，学生说完**自动提交**，全程不用点 Answer / Send。**关**：改成键盘输入（机房没麦时用） |
| 自动连播：开 / 关 | **开**：HanLin 点评完自动问下一题，整节课不用点鼠标，像真的一问一答。**关**（默认）：每题停下来，方便老师追问 |
| 静音判定：1.5s | 学生停下来多久算"说完了"。点一下循环切换 1.0 / 1.5 / 2.0 / 2.5 / 3.0 / 4.0 秒。学生说得慢、习惯中间停顿，就调大一点 |
| 说完等：0.5s | "说完了"之后再等几秒才发出。**默认 1.5 + 0.5，也就是说完停 2 秒自动发送**。想留更长的确认时间就把它调大 |
| 等待开口：15s | HanLin 问完之后，**最多等你开口多久**。点一下循环切换 6 / 10 / 15 / 20 / 30 秒。学生要想一会儿再回答，就调大一点 |
| 题目 | 换成你自己的英文题目（三句，按顺序问）。纠错规则完全不变 |
| 错题库 | 打开 590 条常见错误的对照表（学生可能这样说 → HanLin 改成，附中文说明） |
| AI 纠错：关 / 开 | 打开设置面板，接一个大模型来复核规则认不出的错误。见下面「接入 AI 纠错」一节 |
| 改判 / 手动点评 | HanLin 判错了，或者它没认出的错误你想指出来：可以判成鼓励，也可以**直接把正确的句子敲进去** |
| 记录 / 导出 CSV | 查看和导出全部回答 |
| 中文字幕 | 在英文台词下面显示中文翻译（默认关闭） |
| 演示模式 | 锁住控制条防止上课误触，再点一次解除 |

控制条平时是隐藏的：鼠标移到屏幕顶端，或按 Esc。快捷键：**空格**=开始/停止收音，**回车**=提交框里的答案。

## 错题库里有什么

一共 **590 条**，分两部分：

1. **拼写与缩写、常用搭配**：早期积累的对照表（`alot` → `a lot`、`I go to school yesterday` → `I went to school yesterday`、`different with` → `different from` 等）。
2. **初中英语 200 个常见易错点**，按十个语法板块分类：

| 板块 | 条数 | 板块 | 条数 |
| --- | --- | --- | --- |
| 名词 | 20 | 非谓语动词 | 20 |
| 代词 | 20 | 句子结构、主谓一致、被动语态 | 22 |
| 冠词 | 20 | 宾语从句 | 10 |
| 介词 | 20 | 状语从句与交际用语 | 20 |
| 形容词与副词 | 45 | 动词基础与时态 | 30 |

其中大部分已经写成**自动识别规则**：学生说出带这些错的句子，HanLin 会直接改对，并按"一处错误"点评（`Good try. A small tip: …`）。剩下少数几条（比如 `in class` 和 `in the class` 的区别、`stop to do` 和 `stop doing` 的区别）要看上下文才知道学生想说什么，规则帮不上忙，所以只放进表格给老师参考，HanLin 不会自作主张去改。

点表格右边绿色的句子，会直接填进"改判"框，可以当手动纠错的快捷方式用。

## 接入 AI 纠错（可选）

规则库再大，也只是"见到过的错才会改"。想让它连没见过的错也能认出来，可以接一个大模型。**默认是关的**，不接也完全能用。

### 它是怎么配合的

```
学生说完 → HanLin 先跑自带规则
              ├─ 规则看出毛病 → 直接改句，不联网，瞬间出结果
              └─ 规则没看出毛病 → 交给 AI 复核一遍
                                    ├─ AI 说有错 → 用 AI 改的句子点评
                                    └─ AI 说没错 / 连不上 / 超时 / 乱回答 → 照旧给鼓励
```

所以：**常见错不花一分钱、不占一点网速；只有"规则漏掉"的句子才会走 AI。** AI 挂了也不会影响上课，最坏情况就是退回现在的效果。

### 推荐做法：用一个在线接口（不用装任何东西）

1. 老师控制条 → **AI 纠错：关** → 打开面板；
2. 「服务」选 **DeepSeek（在线）**，地址和模型名会自动填好；
3. 去 [platform.deepseek.com](https://platform.deepseek.com) 注册、充值少量（几块钱够用很久），创建一个 API Key，形如 `sk-...`；
4. 把 Key 粘进「API Key」→ 点**测试连接** → 显示"连接成功"→ 点**保存并开启**；
5. 控制条上的按钮变成 **AI 纠错：开（DeepSeek）** 就好了。

Key 只存在这台电脑的浏览器里。换一台电脑、或者换了浏览器配置，要重新填一次。

面板里还预置了 Kimi、智谱 GLM、通义千问、硅基流动，随便挑一个能用的都行；选「自定义」可以填任何 OpenAI 兼容接口。

### 「复核范围」怎么选

面板里有一项 **复核范围**：

| 选法 | 什么时候用 | AI 什么时候出手 |
| --- | --- | --- |
| **只复核「规则没认出的」句子**（默认） | 平时上课 | 只在规则没看出问题时出手，最省时间、最省钱 |
| **每一句都复核** | 想更严一点，或者担心规则误判 | 每一句都交给 AI 看一眼 |

选「每一句都复核」时，屏幕上会多出一行黄色小字，把两边不一样的地方标出来：

- **AI 也同意上面这个改法。** —— 两边一致，放心用；
- **AI 认为这句其实没问题，可以不改 —— 上面是规则给的改法，由你判断。** —— 规则可能改多了，这时候你可以用控制条的**改判**换成不点评；
- **AI 的改法：……** —— 两边改得不一样，你看着挑。

不管出现哪种，**HanLin 念出来的还是规则那一版**，所以不会出现两个声音打架的情况；AI 的意见只是给你看的一个备注。

### 另一个选择：本地模型（免费，但要先装东西）

如果不想用在线服务，可以在这台电脑上装 [Ollama](https://ollama.com)，然后：

```
ollama pull qwen2.5:3b
set OLLAMA_ORIGINS=*
ollama serve
```

面板里「服务」选 **本地 Ollama**，不用填 Key。`OLLAMA_ORIGINS=*` 那一步不能省，不然浏览器会被本地服务拦下来。

### 要注意什么

- **每次只发学生这一句**，不带姓名、不带前面的问答记录，也不带班级信息。
- 在线服务按量计费：复核一句初二英语大约几十个 token，一个班一节课通常**不到一毛钱**。
- AI 有时会想把句子"改写得更漂亮"。程序做了限制：**含中文、含问号、比原句长一倍以上、或和原句一样的回答一律丢掉**，宁可退回规则结果。
- AI 只负责"改这一句"，**流程还是程序说了算** —— 它没有机会多问一句、闲聊或跑题。

## 语音输入要注意什么
### 麦克风收不到声音怎么办（学生说了没反应，先看这里）

浏览器听写用的是 **Windows 的默认录音设备**。很多笔记本接了蓝牙耳机之后，默认设备会被耳机抢走；而有些蓝牙耳机的麦克风**显示正常但一点声音都收不到**（我在这台机器上实测峰值就是 0.0000），学生说多少遍都没用。

**第一步：跑一次 `切换默认麦克风.bat`**（不需要管理员）

1. 双击它 → 它会列出这台电脑**所有**麦克风，并对每个实测音量（跑的时候对着麦克风说句话，结果更准）；
2. 每行后面写着「能收到声音 ✔」或「几乎收不到」，还会标出是**蓝牙设备 / 虚拟设备 / 内置麦克风**；
3. 按提示输入序号（一般选**内置麦克风**最稳）→ 它就把默认麦克风切过去，并立刻用新设备再测 3 秒确认；
4. 看到「现在能收到声音 ✓」就可以双击 `启动采访-不询问麦克风.bat` 上课了。

**只看不改**：直接运行那个 `.ps1`（不带参数）只会列出来，不会改任何设置，可以放心先看一眼。

**要记住两点**

- **蓝牙耳机每次重新连上，都可能再把默认麦克风抢走**，到时候再跑一次这个脚本就行。
- 脚本只改「默认设备」这一个设置；想还原，就在列表里选回原来的那个名字（脚本会打印「切换前」的名称）。

**如果所有麦克风都测不到声音**

1. 检查物理静音开关（很多笔记本和耳机线上有）、系统音量、麦克风离得是不是太远（15～20 厘米最合适）；
2. 打开 **设置 → 隐私和安全性 → 麦克风**，确认「麦克风访问」和「**让桌面应用访问你的麦克风**」都是开的（脚本也会帮你检查这一项）；
3. 换一个麦克风（USB 领夹麦或带麦的耳机最稳），再跑一次脚本。

### 可选：完全离线的「系统语音输入」（Win+H）

Windows 自带一个**离线**的语音输入：把光标放进答题框，按 **Win+H** 就能说话打字。页面已经配合好了——文字一进来就会当作答案，停一下自动提交；听写整段塞进来时会把等待放宽到 3.5 秒，不会说到一半被发出去。

**但有一个前提**：这台电脑现在只装了**中文**的离线语音包，**系统离线识别还听不懂英语**。想让 Win+H 听英语，需要先装一次：

```
设置 → 时间和语言 → 语言和区域 → 添加语言 → English (United States)
→ 在该语言的「语言选项」里，下载「语音」（Speech）
```

装完之后，把 Win+H 的输入语言切到 English，对着麦克风说英语，文字就会自动落进答题框并提交。这条路不需要网络、不需要 Key，也不需要改课件里的任何东西。

### 听写这一块做了什么（为什么现在更稳）

浏览器自带的英语听写有几个众所周知的毛病，这一版都专门处理过了：

| 原来的毛病 | 现在的处理 |
| --- | --- |
| 浏览器会在没人说话时**自己结束一轮听写**，学生一开口发现已经在"没听清"了 | 只要还在收音时间里，**自动把这一轮接上**；上一轮已经识别出来的词不会丢 |
| 只取识别引擎给的**第一个**候选，常常就是听错的那个 | 一次要 **5 个候选**，挑最像学生真正说的那句（先看引擎置信度，其次优先不需要纠错的那句） |
| 学生想一会儿再答，就被当成"没说话"跳过了 | 新增**等待开口**时间，默认 15 秒 |

顺带说一句：HanLin **自己说话**用的是提前录好的音频，不需要联网、也不受这些影响。只有**听学生说话**这一步要用 Edge 自带的听写服务。

### 麦克风会问你几次

浏览器第一次要用麦克风时会问一次，点「允许」就行；之后这一节课不会再问。

想连这一次都不弹：用文件夹里的 `启动采访-不询问麦克风.bat` 打开（它带"自动允许麦克风"的启动参数，窗口也直接最大化）。

想更省事：把那个 `.bat` **右键 → 发送到 → 桌面快捷方式**，以后上课直接双击桌面图标。

**使用提醒**：这个 .bat 用的是一个独立的 Edge 配置（不会动你平时的收藏夹和书签），而且这个窗口里的麦克风是自动允许的——**别在这个窗口里打开别的网站**。

## 长期使用：哪些会一直有效，哪些要留意

**一定不会过期的**（纯本地，文件里就带着）

- 采访流程、三个问题、HanLin 的预录音频、人物立绘、590 条纠错规则、错题对照表、记录与 CSV 导出。
- 换个文件夹、换台电脑、完全断网，都照常能用。原文件放 U 盘里也能带走。
- 记录和 AI 设置存在浏览器的本地存储里。实测**把 html 换个文件夹打开，记录和 Key 都还在**（同一个浏览器配置下是共享的）。

**可能随时间变化的**（外部依赖）

| 依赖 | 什么时候需要 | 万一不好使了怎么办 |
| --- | --- | --- |
| 学生说话的听写 | 每次学生开口时，用的是 Edge 自带的识别服务（微软），**需要联网** | 控制条把「语音输入」关掉，用键盘输入，其余功能一个都不少 |
| AI 纠错 | 只在你自己打开它之后，且规则没看出毛病时才用 | 余额用完 / 断网 / 服务商改价，都会**自动退回规则模式**，不影响上课 |
| 英文语音包 | 只在改了题目、需要系统朗读时 | 没装也不影响：固定三题的台词是提前录好的音频 |

**两个要留意的点**

1. **用 `.bat` 启动和直接双击 html，是两套浏览器数据**（前者用独立配置，不动你平时的收藏夹）。记录和 API Key 不互通 —— 建议固定用一种方式打开。
2. 启动脚本的浏览器数据放在 `%LOCALAPPDATA%\HanLinEdge`（**不是**系统临时目录），Windows 清理临时文件不会碰到它。如果你之前用过旧版脚本，第一次用新版打开时记录会看不到，重新导一次 CSV 即可。

**养成一个习惯**：下课后点「记录 → 导出 CSV」。浏览器里的记录终究是浏览器数据，导出成文件才算真正存住了。
- **听写需要联网**：学生说的英语是浏览器送去微软的服务器识别的，断网时听写会失败，页面会自动提示你切回键盘输入（HanLin 自己的声音不需要联网）。
- **建议用 Edge**：Edge 用的是微软的服务，国内能连；Chrome 用的是 Google 的服务，常常连不上。
- **教室要相对安静**：麦克风离学生近一点，说慢一点、说完整句，识别率会明显提高。
- **学生说的原话原样留档**：识别出来什么就记什么，一个字都不改（大小写、拼写错误都保留）。HanLin 的修改只出现在"改后句"那一栏。导出的 CSV 里是三栏：`学生原话（识别原文）`、`提交的答案`、`HanLin 改后句`。
- **说完自动发送**：学生停下 1.5 秒判定"说完了"，再等 0.5 秒就自动发给 HanLin——从说完到发出正好 2 秒。想改字或想马上发，在倒计时里点 Send 或直接改（一改就重新计时）。
- **全自动，手都不用碰**：语音模式下 HanLin 一问完就自动开麦，学生说完自动提交，HanLin 自动点评。只有进入下一题需要点一下 **Next question**（把「自动连播」打开就彻底不用点鼠标）。教室再吵也不影响：判定用的是"识别文字有没有变化"，环境噪音不会把计时刷掉。
- 学生说的原话在屏幕上**原样显示**（不划改、不标红），HanLin 的改动只标在"照这样说"那一行。
- **键盘输入也是自动发**：停手 2 秒（静音判定 + 打字保护）再走 0.5 秒倒计时自动发送，不会有"打到一半就被发出去"的情况。
- 识别结果**永远是先落到框里再提交**，所以你看到错了可以马上改。
- 电脑没有麦克风、或者想安静做题：把控制条的**语音输入**关掉，直接用键盘。

## 它是怎么改句子的

改的是**学生自己那句话**，保留他自己的用词，只动语法。比如：

- `I am agree with he.` → `I agree with him.`
- `We are both like music.` → `We both like music.`
- `He don't like music.` → `He doesn't like music.`
- `He like play basketball.` → `He likes to play basketball.`
- `Because I am tall so I can play basketball.` → `Because I am tall I can play basketball.`
- `I am 13 years and I play the basketball.` → `I am 13 years old and I play basketball.`

覆盖的常见错误（40 多类）：

- **主谓一致**：`I are` / `he don't` / `she have` / `he like` / `they is` / `there have` / `there is three books`
- **时态**：`didn't went` → `didn't go`、`don't liked` → `don't like`、`have went` → `have gone`、`has wrote` → `has written`
- **缺 be 动词**：`My partner good at math.` → `My partner is good at math.`、`I very happy.` → `I am very happy.`
- **中文式搭配**：`I am agree`、`we are both like`、`I very like`、`I and my partner` → `My partner and I`
- **名词**：`two book` → `two books`、`many student` → `many students`、`my partner name` → `my partner's name`、`I have 13 years` → `I am 13 years old`
- **介词搭配**：`different with` → `different from`、`good in English` → `good at English`、`listen music` → `listen to music`、`wait you` → `wait for you`、`at the morning` → `in the morning`、`in Monday` → `on Monday`、`with he` → `with him`
- **动词形式**：`can to swim` → `can swim`、`want go` → `want to go`、`enjoy play` → `enjoy playing`、`How about go` → `How about going`
- **比较级**：`more better` → `better`、`as tall than` → `as tall as`
- **其他**：`because…so` → `because`、`although…but` → `although`、`play the basketball` → `play basketball`、`go to home` → `go home`、`interested of` → `interested in`、`I'm interesting in` → `I'm interested in`、`the same like` → `the same as`、`a/an` 混用、大小写（`i` → `I`、`english` → `English`、`monday` → `Monday`）、句尾标点、用中文回答的提醒

它**只改语法，不改意思**；改不到的地方（比如用词不当）不会乱改，这时候用控制条上的**改判**自己写一句。

## 常见问题

**要联网吗？** 只有"听学生说话"需要联网。HanLin 的声音、三个问题、改句、记录全在文件里；断网时把语音输入关掉，用键盘照样上课。

**要装语音包、要填 Key 吗？** 都不要。

**麦克风打不开（学生说了没反应）？** 这是最常见的问题，多半是浏览器没给麦克风权限。现在页面自己会管这件事：

1. 点「开始采访」时，页面会主动申请一次麦克风权限，浏览器会弹出授权框 —— **点「允许」**；
2. 如果权限被拒、或者电脑没插麦克风，**屏幕上方会出现一条红色提示**，用中文写清楚下一步怎么做，上面还有「重试」按钮。老师允许权限之后点一下「重试」就能接着上课，不用重启页面；
3. 最省事的办法还是**用 `启动采访-不询问麦克风.bat` 打开** —— 它会让浏览器直接允许麦克风，从头到尾不弹框。

顺带提醒：`.bat` 用的是独立的 Edge 配置，如果你之前是在另一个配置里点过"允许"，换成 `.bat` 打开时相当于换了套浏览器数据，权限要重新给一次（`.bat` 会自动给）。

**识别不准？** 离麦克风近一点、说慢一点；实在不行直接改框里的字。教室特别吵的话建议关掉语音输入用键盘。

**没声音？** 先检查系统音量是不是静音了。所有语音都是文件自带的，和系统语音包无关。

**找不到控制条？** 把鼠标推到屏幕最顶端，或者按 Esc。

**记录存在哪？** 存在这台电脑的浏览器里。换电脑或清缓存会丢，所以课后记得导出 CSV。

**想换题目？** 三句话和全部流程写在 `HanLin采访-离线版.html` 里的 `SCRIPT` 常量里，可以改；改完自己再走一遍。

## 注意事项

- 记录只存在本机浏览器里，课后导出 CSV 存档。
- 整个文件夹一起拷贝，别把采访页从课件旁边挪走。
- 语音输入依赖浏览器自带的识别服务，属于"联网可用"，不是隐私敏感场景：不要把学生的敏感信息录进去。
