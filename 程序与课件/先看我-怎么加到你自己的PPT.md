# 先看我：3 分钟就能用起来

这是一位"校报小记者 HanLin"：他用初二水平的英语按固定顺序问三个问题，**学生对着麦克风说英语、页面自动转成文字**，他当场接话——没语法错误就说 `Great!` / `Good job!`；有语法错误就**把学生那句话直接改对**，屏幕上并排显示原句和改后句，错的词划红、改对的词高亮。整节课下来就像 HanLin 真的在和学生一问一答。

**不用装任何东西、不用注册、不用填 API Key。** HanLin 的声音和全部台词都在文件里；只有"听学生说话"那一步需要联网。

---

## 第 0 步：解压

把压缩包解压到一个普通文件夹里，比如 `D:\HanLin采访\`。**不要在压缩包预览窗口里直接双击文件**，那样链接会失效。

解压后你会看到：采访主程序（`HanLin采访-离线版.html`）、一份 10 页成品课件、角色图片、这份说明和一份详细说明。**它们要一直待在同一个文件夹里**，课件上的按钮才不会断。

## 用法一（最省事）：直接用附带的课件

打开 `英语采访HanLin-完整课件.pptx`，按 **F5** 放映。翻到第 1、5、6、7、8 页时，点页面上蓝色的 **Start the interview**，就会弹出浏览器打开采访页。讲完按 Alt+Tab 回到课件。

## 用法二：接进你自己的 PPT

1. 新建一个文件夹，把**你自己的 `.pptx`** 和 `HanLin采访-离线版.html` 都拷进去。PowerPoint 的超链接是相对路径，两个文件待在一起，整个文件夹搬到别的电脑也不会断。
2. 在你 PPT 的某一页上，选中你想让学生点的那句话或那张图（比如写着 "Start the interview" 的文本框）。
3. 右键 → **链接**（旧版叫"超链接"）→ 左边选 **现有文件** → 选中 `HanLin采访-离线版.html` → 确定。想在哪几页放入口就重复几次。
4. 按 **F5** 试一下，点那个入口应该会弹出浏览器打开采访页。

> 点不开就检查一件事：`.pptx` 和 `HanLin采访-离线版.html` 是不是在同一个文件夹里。

## 上课怎么用

1. **用 Edge 打开** `HanLin采访-离线版.html`（Chrome 也行，但 Chrome 的英语听写在国内常常连不上），按 **F11** 全屏。
   **更省事、也最不容易出问题：双击 `启动采访-不询问麦克风.bat`**——它用 Edge 打开采访页，麦克风自动允许、**不弹询问**。
   直接双击 html 的话，浏览器会弹一次麦克风询问，**必须点「允许」**，否则学生说话没反应。忘了点或点了拒绝也不要紧：屏幕上方会跳出一条红色提示，照它写的做完点「重试」就能继续，不用重启页面。
2. 鼠标移到**屏幕顶端**（或按 **Esc**）弹出老师控制条 → 填组名 → 点**开始采访**。
3. HanLin 问完第 1 题后，学生点 **🎤 Answer**（或按**空格**）开始说英语；说完停顿一下自动停止，文字出现在框里，再过一秒自动提交。
4. HanLin 立刻接话：
   - 没语法错误 → `Great!` / `Good job!`
   - 有语法错误 → `Good try. A small tip:` 加上屏幕上的两行：

     ```
     You said          We are both like music and I am agree with he.
     Say it like this  We both like music and I agree with him.
     ```

5. 点 **Next question** 进下一题；三题问完是收尾台词；改好组名点 **Next group** 继续下一组。
6. 课后：控制条 → **记录** → **导出 CSV**，Excel 直接打开。

## 三个好用的开关

- **语音输入：开 / 关**：开着就是学生说、自动转文字；教室太吵或没麦克风就关掉，改成键盘输入。
- **自动连播：开 / 关**：打开后 HanLin 点评完会自己问下一题，整节课不用点鼠标，最接近"真人对话"。默认关着，方便老师每题追问两句。
- **静音判定：2.0s / 说完等：2.0s**：学生停下来 2 秒算说完，再倒计时 2 秒自动把答案发出去；**键盘输入也一样，停手 2 秒自动发**。这两个数字点一下就能改（1.0～4.0 秒）；等待期间可以改字（一改重新计时），也可以按 Send 马上发。
- **改判 / 手动点评**：HanLin 判错了、或者它没认出的错误你想指出来，可以直接把正确的句子敲进去，屏幕就显示你这一句。
- **题目**：想换三句话就点这里，只能填英文；**纠错规则完全不变**。默认那三句有 HanLin 的原声，自己写的题目只显示文字（装了英文语音包才会读出来）。
- **错题库**：HanLin 内置了 **590 条**常见错误的对照表，其中包含**初中英语 200 个常见易错点**（按名词、代词、冠词、介词、形容词与副词、动词与时态、非谓语动词、句子结构与被动、宾语从句、状语从句与交际用语十个板块分类），点任意一条可以直接填进"改判"框手动用。

- **想让它更聪明**：控制条上有 **AI 纠错**，默认关着。打开并填一个 API Key（推荐 DeepSeek，几块钱能用很久），规则认不出的错也会交给大模型复核；把它设成「每一句都复核」，屏幕上还会标出"规则"和"AI"两边不一致的地方。AI 连不上会自动跳回离线规则，上课不会卡。详见《使用说明》里的"接入 AI 纠错"。

- **听不清学生说话**：控制条上三个旋钮配合用 —— **等待开口**（学生想一会儿再答，默认 15 秒）、**静音判定**（多久算说完了，默认 1.5 秒）、**说完等**（说完再等几秒才发送，默认 0.5 秒）。教室吵就把静音判定调到 2～3 秒。浏览器自己中断时程序会自动接上，学生不用重说。

**没听清**：HanLin 会说 `Sorry, I didn't catch that. Please say it again.` 并等你重说，不会跳题。

**找不到控制条**：把鼠标推到屏幕最顶端，或者按 Esc。上课怕误触就点**演示模式**锁住它。

## 语音输入的两条前提

1. **要联网**。学生说的英语是浏览器送去服务器识别的，断网时听写会失败，页面会提示你切回键盘输入（HanLin 自己的声音不需要联网）。
2. **最好用 Edge**。Edge 用微软的服务，国内能连；Chrome 用 Google 的服务，常常连不上。

**麦克风会问你几次**：第一次用麦克风时浏览器会问一遍，点「允许」就行，之后一节课不会再问。想连这一次都不弹，就用 `启动采访-不询问麦克风.bat` 打开（推荐，带"自动允许麦克风"的参数，窗口还直接最大化）；用这个 .bat 的窗口是自动允许麦克风的，**别在里面开别的网站**。

**学生说了没反应（收不到声音）**：先双击 `切换默认麦克风.bat`——它会列出所有麦克风、实测音量，并把 Windows 默认麦克风切到能收到声音的那个（蓝牙耳机经常抢走默认设备又收不到声音）。只看不改也行，直接运行那个 `.ps1` 就只列出来。想看完全离线的路子（Win+H 系统语音输入）怎么开，见《使用说明》里的「麦克风收不到声音怎么办」。

**不想经过浏览器**：双击 `HanLin采访-桌面版.exe`，出来的是自己的窗口（没有地址栏、没有标签页、不弹麦克风询问）。它要和那 3 个 `.dll`、以及采访页放在同一个文件夹里。如果被 Windows 拦住，改用 `上课-独立窗口.bat`，效果基本一样。

**关于"能不能一直用"**：稿子、录音、人物、590 条纠错规则、错题表、记录导出全都在文件里，不算时间、不联网也能用。只有两处依赖外部：①学生说话的听写（用 Edge 自带的在线识别，要联网）；②你选装的 AI 纠错。这两处一旦不可用，程序会自动退回（听写→键盘输入，AI→离线规则），上课不受影响。另外建议**固定用同一个方式打开**（.bat 或双击 html 二选一），因为两种方式的记录和 Key 不互通。

## 它改哪些错误

HanLin 说话时是**双字幕**：英文在上（主体、大字），中文在下面（略小、灰色）——开场白、三个问题、表扬、改句提示、收尾句都有中文。控制条上可以一键把中文字幕关掉，上纯英文课用。

只改语法，不改学生的意思，保留他自己的用词，覆盖 40 多类常见错误：主谓一致（`I are` / `he don't` / `she have` / `they is` / `there have`）、时态（`didn't went` → `didn't go`、`have went` → `have gone`）、缺 be 动词（`My partner good at math.` → `My partner is good at math.`）、中文式搭配（`I am agree`、`we are both like`、`I very like`、`I and my partner`）、名词单复数与所有格（`two book` → `two books`、`my partner name` → `my partner's name`）、介词搭配（`different with` → `different from`、`good in English` → `good at English`、`listen music` → `listen to music`、`at the morning` → `in the morning`、`with he` → `with him`）、动词形式（`can to`、`want go` → `want to go`、`enjoy play` → `enjoy playing`）、比较级（`more better`、`as tall than`）、`because…so` / `although…but`、`play the basketball`、`go to home`、`a/an`、大小写和句尾标点。用中文回答也会被提醒改用英语。

更细的用法和常见问题看同目录的 `使用说明.md`。
